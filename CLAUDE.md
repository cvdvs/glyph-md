# CLAUDE.md — Glyph

Native Mac markdown reader/editor (Obsidian-style live preview for single files). Keep it simple and dependency-free; explain changes in plain language.

**Read first:** `README.md` (what it is, how it's built, dev workflow).

Rules for this project:

1. **The app is Objective-C on purpose** — it must keep building with `clang` and Apple's Command Line Tools alone (no Xcode, no Swift, no package manager). Don't port it.
2. **Build with `./build.sh`**, then reinstall: `rm -rf /Applications/Glyph.app && cp -R build/Glyph.app /Applications/` and re-run `lsregister -f /Applications/Glyph.app`. Quit a running Glyph before reinstalling.
3. **All visual/rendering/editing changes happen in `Resources/viewer.html`** — it's the entire UI. Verify with `python3 Scripts/make-preview.py sample.md <out.html>` in a browser (both color schemes) and with the headless WebKit harness (`Scripts/webkit-smoke.m`) before rebuilding the app.
4. **No new dependencies.** `marked.min.js` is vendored; the app must work offline and build with nothing but clang.
5. Keep `sample.md` in sync with what the viewer supports — it's the feature checklist.
6. **The formatted view is a live WYSIWYG editor.** `#md` is `contenteditable`; the serializer in `viewer.html` (`serializeDoc`/`serializeBlock`/`serializeInline`) converts the rendered DOM back to markdown and posts `{type:"source", text}` through the `glyph` WKScriptMessageHandler on a 600ms debounce (`glyphFlush` forces it; the native side flushes before save and before switching to raw mode). **The renderer and serializer are mirror images** — every element the renderer can produce, the serializer must reverse (unknown elements fall back to `outerHTML`). If you add a rendered feature, add its serialization, or edits will strip it from files.
7. **Invisible characters are a real hazard in `viewer.html`:** contenteditable produces non-breaking spaces (U+00A0) and the inline typing rules insert zero-width spaces (U+200B). All normalization regexes must use explicit escapes written as `\u00a0` and `\u200b` — literal invisible characters in source do not survive editing tools. If typing rules stop matching, search the file for a raw U+00A0 first.
8. **Typing rules must run deferred** (one `setTimeout(0)` after the input event) — running execCommand re-entrantly inside the input dispatch half-applies. The browser also sometimes nests a freshly created list inside the old paragraph; `convertToList` unwraps it and the serializer's block-in-paragraph path catches whatever slips through.
9. Native toolbar/menu formatting actions are dual-routed: raw mode edits the NSTextView, formatted mode calls `window.glyphToolbar('<cmd>')` in the page.
10. **The chrome layer is strictly gated.** Everything that gives the standalone build its tabs/toolbar/open-save lives inside `window.__glyphInstallChrome`, runs only when `window.__glyphChrome` is set, and its CSS is scoped under `body.glyph-chrome`. macOS never sets the flag. An ungated line — a stray CSS rule or a listener bound outside the installer — is the one way this can regress the Mac app, so the golden-file assertion in CI is what proves it hasn't.
11. **The raw editor's gutter is not a view.** Line numbers are painted by `GlyphTextView -drawViewBackgroundInRect:`. An NSRulerView (or any view added to that scroll view) stops the text view drawing its glyphs entirely — blank pane, correct attributes, very hard to diagnose. Don't reintroduce one.
12. **A markdown document is untrusted input.** Notes arrive from model output, downloads and cloned repos, so `viewer.html` sanitizes marked's HTML with an allowlist (`sanitizeHTML`) before it reaches the document, and our own trusted markup is added afterwards. Remote images are held behind a click so opening a note cannot phone home. The native side only hands `http`/`https`/`mailto` to NSWorkspace and cancels every navigation that is not the initial load. `Scripts/security-smoke.js` runs against `Scripts/fixtures/hostile.md` in both engines in CI — if you touch the render path, that suite is what proves you did not reopen the hole.
13. **Never embed a document into a `<script>` block with plain JSON.** `json.dumps`/`JSON.stringify` do not escape `<`, so a file containing `</script>` closes the block and executes as HTML, bypassing the sanitizer completely. `Scripts/make-preview.py` and `Scripts/engine-smoke.mjs` both escape `<` to `\u003c`; keep it that way.
14. **Display-only attributes must never reach the file.** The serializer is what writes the user's document, so anything the app adds for rendering (`data-remote-src`, `data-alt`, `.remote-img`) has to be stripped or reversed there — see `serializeImg`. A standalone image is a *block*, so `serializeBlock` needs its own case; its `outerHTML` fallback would otherwise write our internals into the note.
15. **Glyph never deletes content; it may escape it so it stays inert.** The sanitizer runs on render and the serializer writes the sanitized DOM back to the user's file, so anything the sanitizer *removes* is removed from their document. An unclosed `<style>` used to swallow the rest of the note and delete it on save (measured: 10 paragraphs down to 2). `guardInput` in `viewer.html` escapes swallowing tags and over-long emphasis runs before `marked.parse`, so nothing is swallowed and nothing is lost. That pre-pass is content preservation, not a security control — the DOM sanitizer stays authoritative, so a miss there is free.
16. **Both parsers are quadratic on adversarial input and both run on the main thread.** marked's emphasis tokenizer is O(n²) in `*`/`_` per line (a long run froze the app on *open*), and `GlyphHighlighter`'s inline-code rule was O(n²) via its backreference (froze ⌘E for a minute). Both are bounded now — `EMPHASIS_LIMIT` in `guardInput`, and `{1,10}`/`{1,500}` plus a 20k line cap in the highlighter. Never reintroduce an unbounded quantifier next to a backreference, and never assume a note is well-formed: an LLM emitting a wall of punctuation is enough.
17. **Never set `allowFileAccessFromFileURLs`.** It is not needed for images — those resolve through the base URL, verified — and it converts any script execution into an arbitrary local-file read.
18. **The CSP is load-bearing and has two forms.** The macOS app substitutes a fresh nonce per load in `-loadTemplateHTML` (not in `+viewerTemplate`, which is cached once per process); `make-preview.py` and `engine-smoke.mjs` pin the same inline blocks by sha256 because a static file has no per-load step. If you add or edit a `<script>`/`<style>` block, all three paths must be updated together or the page silently stops running.
19. **The autosave guard is the last line of defence for the user's files.** `-verifyRoundTrip` renders the document, asks the page what it would be written back as, and compares word bags (`GlyphRoundTripPreservesContent`). If any word would be lost, the formatted view is switched to read-only via `glyphSetProtected` and page-sourced edits are refused outright — the raw view (⌘E) stays available because it writes the file literally. The rule is deliberately blind to formatting: bullet markers, blank lines and autolinking must NOT trip it or the app becomes unusable, and entity references are stripped from both sides before counting. Measured on 264 of the owner's real files: 248 editable, 16 protected. Use `Scripts/roundtrip.m` to re-measure after any serializer change.
20. **A pipe inside `[[target|alias]]` is part of the link, not a table column break — and BOTH spellings must survive verbatim.** `guardInput` marks them before marked's table parser runs, because that parser consumes a backslash escape when it splits cells and it cannot be recovered afterwards: U+E001 marks one the author escaped, U+E000 one we escaped, and the wikilink renderer restores each to what it was. `serializeTable` skips pipes inside wikilinks so nothing is re-escaped on the way out. Never normalize one form into the other — Obsidian expects `\|` inside tables, so rewriting it changes how those files render elsewhere.
21. **The guard needs a construct census, not just words.** A paragraph holding only `&nbsp;` carries no words, so 81 deliberate blank answer lines vanished from a client brief while the word check reported it safe. `GlyphTakeCensus` counts blank-but-not-empty lines, comments, fences, images, headings and table rows, and only DECREASES trip the guard — normalization legitimately adds constructs (setext becomes ATX, blank lines get inserted) and firing on that would make the app unusable. Re-measure with `Scripts/roundtrip.m` after any serializer change.
22. **Imported HTML documents will never round-trip and should not pretend to.** Old blog captures and epub conversions carry styling in classes and wrappers that the sanitizer strips for safety before the serializer sees them, so they cannot be written back honestly. The right answer is the guard holding them read-only, not a preservation path that looks complete and is not.
23. **Links between notes are supposed to work.** `[other](other.md)` opening the sibling note is how a wiki is written, and it was killed once by the http/https/mailto allowlist. `GlyphActionForURL` now returns one of three outcomes: web and mail links go to NSWorkspace, an EXISTING markdown file opens as a Glyph document (not via LaunchServices, so a link to a `.command` or `.app` cannot launch anything), everything else is ignored. `Scripts/link-smoke.m` is the decision table and runs in CI — if you touch the URL policy, that test is what proves you did not break wiki links or open a hole.
24. **Some documents are too big for the formatted view, and that is fine.** Past `kGlyphFormattedViewLimit` (300KB) the app opens straight into the raw view and `renderMarkdown` returns early; the highlighter stops coloring above 400KB but keeps line numbers. Measured before this: a 1.6MB note froze the window for 17s, a 2MB one for 143s, and a 3.3MB one never finished — the render process had died and nothing was listening, so the pane stayed white forever and every later file in that window was blank too. `-webViewWebContentProcessDidTerminate:` now reloads. Only 48 of her 57,542 files are above the ceiling; the 3.3MB file settles in 2s.
25. **Her files change on disk while they are open** — Claude Code sessions rewrite the very notes she is reading. `-presentedItemDidChange` reloads when the document is clean and stands aside when it is not. Never make this reload over unsaved edits.
26. **Anything that commits or discards a document must flush the page first.** The formatted view batches edits for 600ms; `glyphFlush()` now RETURNS the text so `-flushPageThen:` is a handshake rather than a fixed delay that lost on large files. `saveDocument:`, `saveDocumentAs:` and `canCloseDocumentWithDelegate:` all go through it — before, ⌘W within 600ms of typing closed with no save prompt at all, because the document did not yet know it was dirty.
27. **`-dataOfType:` returns `self.text`, never the text view.** Every edit path lands in `self.text`; reading the view instead meant a save arriving at the wrong moment could write whichever copy was behind.
28. **`Scripts/roundtrip.m` must use the same rule as the app.** It briefly did not — it kept the word check and dropped the census — so a measurement was reported from a weaker rule than the one shipping. If `GlyphRoundTripPreservesContent` changes, change the harness copy in the same commit.
29. **A wikilink target is a NAME, never a path.** `GlyphVault basenameForTarget:` strips alias, heading anchor, block anchor, extension and — the load-bearing part — everything up to the last `/`, `\\` or `:`, so `[[../../../../etc/passwd]]` reduces to `passwd` and can only ever match a file inside the note's own vault. The page sends the target text and never builds an href; the app decides what file it means. The vault root is the nearest ancestor holding `.obsidian` or `.git`, bounded to 6 levels, and the scan is capped at 40,000 files. `Scripts/vault-smoke.m` is the test and runs in CI — every traversal case in it must keep returning nil.
30. **A hard line break must survive, a soft wrap must not become one.** marked runs with `breaks: true`, so both render as `<br>` and are indistinguishable in the DOM — but they are NOT the same elsewhere: in Obsidian a soft newline joins the lines, so dropping two trailing spaces changes how the document reads there. `guardInput` replaces the trailing spaces with U+2060 before parsing, `serializeInline`'s BR case checks the preceding text node for it, and the joiner is stripped from all serialized text so it never reaches the file.
31. **A guard that protects more files is not automatically better.** A `hardBreaks` counter was added to `GlyphTakeCensus` and then REMOVED: it pushed the protected count from 16 to 21, and two rounds of refinement only reached 19, because trailing spaces at the end of a list item, heading or quote are inert in every renderer and their loss is not a loss. The preservation fix stands on its own and is pinned by the fidelity suite. Re-measure with `Scripts/roundtrip.m` before adding any census signal, and drop it if the protected count rises — the app going read-only on her files is worse than the churn it would catch.

32. **The vendored library's JSON reader must never touch a document.** `webview::detail::json_unescape` handles `\b \f \n \r \t \\ \/ \"` and then `default: // TODO: support unicode decoding — return -1`. `JSON.stringify` emits `\uXXXX` for every control character outside those five, so a note containing an ESC — every ANSI colour code in pasted terminal output — makes the parse FAIL, and a failed parse returns an empty string. The shell would then write that empty string over the note. Measured: U+0007, U+000B, U+001B and a lone surrogate all came back as zero bytes. `shell/glyph_json.h` is Glyph's own decoder (full `\u`, surrogate pairs, U+FFFD for a lone surrogate rather than refusing the whole document), and a failed decode REFUSES the save instead of writing nothing. `Scripts/json-smoke.cc` is the test and runs in CI; every case in it is a file that the library's reader would have destroyed. If the vendored library is ever refreshed, this stays.

33. **A CI job that only compiles proves nothing here, and a green job is not automatically a passing one.** Every interesting failure in the portable build happens at runtime and looks like a blank window, so both platform jobs BUILD and RUN `--selftest`. The Windows job once went green with an empty log: PowerShell does not wait for a GUI-subsystem process, so `& glyph.exe --selftest` returned instantly and `$LASTEXITCODE` held the previous command's 0. It now uses `Start-Process -Wait -PassThru` and requires the log to contain `selftest: all pass`, so an empty or truncated run cannot pass either. The same shape of mistake is worth checking for anywhere a test's success is inferred rather than read.

34. **The portable shell has no console, so it writes its own log.** `--selftest` tees to `glyph-selftest.log` because the Windows binary is a GUI-subsystem app and `AttachConsole` finds nothing to attach to on a runner — the first Windows failure arrived with not one line of output. A run that never hears `ready` from the page is an explicit failure naming the page it tried to load, since the window closing on its own is otherwise indistinguishable from a suite failing.

35. **A serializer delimiter must be sized to its content.** A code span was always wrapped in ONE backtick and a fenced block in THREE, so a code span containing a backtick (`` ``a`b`` `` → `` `a`b` ``) and a fenced block showing a ``` example (4-backtick or `~~~` fence) were silently corrupted on the next edit — reachable even on the shipping macOS app, because the autosave guard counts words and fence LINES, not delimiters, so no word is lost and it waves them through. `backtickFence(content, min)` in `viewer.html` sizes the run one longer than the longest backtick run in the content (CommonMark); `serializeCodeSpan` pads with a space when the content edges are backticks. A `~~~` fence normalizes to backticks losslessly. `Scripts/fidelity-smoke.js` pins both. Never hard-code a delimiter length again.

36. **The portable shell's tab model is FIFO, and `Tabs::docs` is a `std::deque`.** The page mints tab ids and reports them back in the order opens were issued, so `shell/glyph_docs.h` parks paths in a queue and binds each "opened" to the OLDEST parked path. A single slot bound the first tab to the LAST file — multi-select Open then overwrote a different note on the next save. `docs` is a deque, not a vector, because `opened()`/`find()` hand out `Doc*` that callers use across later opens and a vector's `push_back` would reallocate and dangle them. `Scripts/docs-smoke.cc` is the test (runs in CI on all three platforms); every multi-open case in it fails against a single slot or a vector.

37. **The portable shell flushes the active document on tab-switch and on close.** It has no save-prompt (the webview library exposes no window-close hook) and no round-trip guard (that machinery is macOS-only), so `flush_active` writes a path-backed document rather than lose the owner's edits silently — `g.pending` is the page's own serialized output, exactly what an explicit Save writes. Because there is no guard, the serializer must be trusted on this path: fix serializer bugs at the source (see rule 35), never rely on the shell catching them. An untitled document still needs an explicit Save-As; it cannot be flushed with no location.

38. **The Glyph server writes files, so its atomic write must be symlink-proof.** `server/glyph-server.mjs` serves a folder of untrusted notes over the LAN; the served folder can hold symlinks (cloned repos, shared vaults — git preserves them). `writeAtomic` once wrote to a predictable temp path `<note>.glyph-tmp` with a plain open that FOLLOWS a symlink, so a planted `<note>.glyph-tmp` → `~/.zshrc` turned one edit into an out-of-folder write (proven: the outside file was overwritten). It now uses a RANDOM temp name created with `flag:"wx"` (O_EXCL refuses any existing entry, symlink included), and the write handler realpaths the PARENT directory and requires it inside the root (closing a new-file-in-symlinked-subdir escape) — the same lesson as the C++ shell's O_NOFOLLOW (audit rule). `Scripts/server-smoke.mjs` plants a temp symlink and a symlinked subdir and asserts nothing escapes; it runs in CI. Token compare is on BYTE length (a high Latin-1 header byte otherwise crashed timingSafeEqual to a 500).

39. **Server-mode autosave state is per-document, and explicit Save respects the conflict guard.** In `viewer.html` server mode, `d.saveTimer`/`d.saving` live on each doc, not as module singletons — a shared timer let one open note's edit cancel another's pending save and orphan it. An offline save keeps `pendingSave` and retries unconditionally (plus a window `online` flush), because the failed text never persisted. Explicit Save sends `baseMtime` and forces past a 409 ONLY when a conflict is already showing (`d.conflict`), so a reflexive Save cannot silently clobber a version a Claude Code session just wrote to disk (rule 25) — a deliberate second Save after the warning does. There is no round-trip guard on this path, so the serializer must be trusted at the source (rule 35).

40. **A `.txt` is plain text and must come back byte for byte.** `.txt`/`.text`/`.log` open in the LITERAL view on every surface and never reach `marked` or the serializer: the formatted view normalizes what it edits (bullet markers, spacing, delimiters — rule 35), which is correct for a `.md` and destructive for a file whose whole contract is "unchanged". macOS: `-isPlainText` forces `self.editing`, refuses the Read/Edit toggle with an explanation, disables the markdown highlighter (a leading `#` is not a heading in a `.txt`), and short-circuits `-renderMarkdown`/`-verifyRoundTrip`. Page: `isPlainName()` sets `d.plain`, `activate()` pins `glyph-raw` and skips the render, `toggleRaw` refuses, and the raw textarea's input handler is where a plain file's autosave is triggered. Server: `isServable()` covers both kinds. Proven, not assumed — a `.txt` of asterisks, `#hashtags`, indentation and trailing spaces was opened in the Mac app (sha256 unchanged) and edited over the phone server (only the typed text differed). `Scripts/engine-smoke.mjs --with-chrome` and `Scripts/server-smoke.mjs` pin it. Never route a plain file through the markdown path to "make it prettier".

41. **The viewport meta is the whole ballgame on a phone, and the fixed bar's height must be MEASURED.** Without `<meta name="viewport" content="width=device-width, …, viewport-fit=cover">` a phone lays the page out at ~980px and scales the result down, so every `max-width: 640px` rule never matches and the interface arrives as a shrunken desktop — which is exactly how it shipped until it was measured (`innerWidth` reported 980 on an emulated 390px iPhone). `viewport-fit=cover` is what makes the `env(safe-area-inset-*)` padding work around the notch and home indicator. Separately, `#glyph-bar` is `position: fixed`, so the body must be padded by its EXACT height — 86px on a desktop but 99px on a phone, so a hardcoded value hides the first lines under the toolbar on one of them. `syncBarHeight()` measures it into `--glyph-bar-h` and a `ResizeObserver` keeps it right through rotation. `Scripts/engine-smoke.mjs --with-chrome` asserts the meta, the measurement, `position: fixed`, and that the padding matches.

42. **The reader's text size scales the document, never the chrome.** Everything inside the page is sized in `em` from `body`'s font-size, and the chrome is in fixed `px`, so one `--reader-size` variable scales the prose while the toolbar and tabs hold still. The mobile stylesheet sets `--reader-size` rather than pinning `#md`, because a fixed `font-size` there would win the cascade and make A−/A+ do nothing on the one screen it matters on. Clamped to 13–26px and remembered per device; unset means "follow the screen".

43. **A macOS LaunchAgent cannot read ~/Documents, ~/Desktop or ~/Downloads, and cannot ask.** Measured on macOS 26.5.2: an agent could not list `~/Documents`, read a script inside it, or list the served folder — every attempt denied, no prompt, no log. Since BOTH this repo and the owner's notes live under `~/Documents`, the always-on launch agent cannot work here at all: launchd exits 127 with `/bin/zsh: can't open input file`, then retries forever, and from the phone it just looks like the server vanished. `Scripts/glyph-server-agent.sh` therefore refuses to install when either the served folder or the repo is under a protected folder, and names what does work. What DOES work with no permission at all is `Scripts/Start Glyph Server.command`, double-clicked: Terminal already holds the Documents grant, so the server inherits it. Never ship a background agent for a path under those three folders without a permission grant the user has actually made.

44. **The pairing token is printed only to a TTY, never to a log.** The server's banner carries the full pairing URL; when stdout is redirected the token is omitted and the banner points at `~/.config/glyph/server-token` (mode 0600) instead. This is not theoretical: the first log this wrote lived at `/tmp/glyph-server.log`, mode 0644, inside a world-readable `/tmp`, with the token in it three times — and `docs/mobile.md` had baked that path into its launchd example. `Scripts/server-smoke.mjs` asserts both that the token is readable from its file and that it does NOT appear in non-interactive output.

45. **On a phone, an unsaved edit must exist somewhere other than a JavaScript variable.** iOS discards a backgrounded tab with no warning, `beforeunload` does nothing there, timers in a hidden tab are throttled or stopped, and losing cellular signal usually fires no `offline`/`online` event at all — so the retry that "should" run while she walks does not. Every pending edit is therefore snapshotted to `localStorage` (`glyphDrafts`) and offered back on the next open; `visibilitychange` snapshots on the way out and retries immediately on the way back, because it is the only hook that fires reliably. A save request carries a 10s `AbortController` timeout (a stalled link otherwise blocks every retry behind `d.saving` with nothing on screen), retries back off to 30s, and a 401 stops retrying and says the phone is no longer paired rather than promising a retry that can never succeed. A 409 never auto-retries.
