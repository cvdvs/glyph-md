# CLAUDE.md — Glyph

Native Mac markdown reader/editor (Obsidian-style live preview for single files). Keep it simple and dependency-free; explain changes in plain language.

**Read first:** `README.md` (what it is, how it's built, dev workflow).

Rules for this project:

1. **The app is Objective-C on purpose** — it must keep building with `clang` and Apple's Command Line Tools alone (no Xcode, no Swift, no package manager). Don't port it.
2. **Build with `./build.sh`**, then reinstall: `rm -rf /Applications/Glyph.app && cp -R build/Glyph.app /Applications/` and re-run `lsregister -f /Applications/Glyph.app`. Quit a running Glyph before reinstalling.
3. **All visual/rendering/editing changes happen in `Resources/viewer.html`** — it's the entire UI. Verify with `python3 Scripts/make-preview.py sample.md <out.html>` in a browser (both color schemes) and with the headless WebKit harness (`Scripts/webkit-smoke.m`) before rebuilding the app.
4. **No new dependencies.** `marked.min.js` is vendored; the app must work offline and build with nothing but clang.
5. Keep `sample.md` in sync with what the viewer supports — it's the feature checklist.
6. **The formatted view is a live WYSIWYG editor.** `#md` is `contenteditable`; the serializer in `viewer.html` (`serializeDoc`/`serializeBlock`/`serializeInline`) converts the rendered DOM back to markdown and posts `{type:"source", text}` through the `glyph` WKScriptMessageHandler on a 600ms debounce (`glyphFlush` forces it; the native side flushes before save and before switching to raw mode). **The renderer and serializer are mirror images** — every element the renderer can produce, the serializer must reverse (unknown elements fall back to `outerHTML`). If you add a rendered feature, add its serialization, or edits will strip it from files.
7. **Invisible characters are a real hazard in `viewer.html`:** contenteditable produces non-breaking spaces (U+00A0) and the inline typing rules insert zero-width spaces (U+200B). All normalization regexes must use explicit escapes written as `\u00a0` and `\u200b` — literal invisible characters in source do not survive editing tools. If typing rules stop matching, search the file for a raw U+00A0 first.
8. **Typing rules must run deferred** (one `setTimeout(0)` after the input event) — running execCommand re-entrantly inside the input dispatch half-applies. The browser also sometimes nests a freshly created list inside the old paragraph; `convertToList` unwraps it and the serializer's block-in-paragraph path catches whatever slips through.
9. Native toolbar/menu formatting actions are dual-routed: raw mode edits the NSTextView, formatted mode calls `window.glyphToolbar('<cmd>')` in the page.
10. **The chrome layer is strictly gated.** Everything that gives the standalone build its tabs/toolbar/open-save lives inside `window.__glyphInstallChrome`, runs only when `window.__glyphChrome` is set, and its CSS is scoped under `body.glyph-chrome`. macOS never sets the flag. An ungated line — a stray CSS rule or a listener bound outside the installer — is the one way this can regress the Mac app, so the golden-file assertion in CI is what proves it hasn't.
11. **The raw editor's gutter is not a view.** Line numbers are painted by `GlyphTextView -drawViewBackgroundInRect:`. An NSRulerView (or any view added to that scroll view) stops the text view drawing its glyphs entirely — blank pane, correct attributes, very hard to diagnose. Don't reintroduce one.
12. **A markdown document is untrusted input.** Notes arrive from model output, downloads and cloned repos, so `viewer.html` sanitizes marked's HTML with an allowlist (`sanitizeHTML`) before it reaches the document, and our own trusted markup is added afterwards. Remote images are held behind a click so opening a note cannot phone home. The native side only hands `http`/`https`/`mailto` to NSWorkspace and cancels every navigation that is not the initial load. `Scripts/security-smoke.js` runs against `Scripts/fixtures/hostile.md` in both engines in CI — if you touch the render path, that suite is what proves you did not reopen the hole.
13. **Never embed a document into a `<script>` block with plain JSON.** `json.dumps`/`JSON.stringify` do not escape `<`, so a file containing `</script>` closes the block and executes as HTML, bypassing the sanitizer completely. `Scripts/make-preview.py` and `Scripts/engine-smoke.mjs` both escape `<` to `\u003c`; keep it that way.
14. **Display-only attributes must never reach the file.** The serializer is what writes the user's document, so anything the app adds for rendering (`data-remote-src`, `data-alt`, `.remote-img`) has to be stripped or reversed there — see `serializeImg`. A standalone image is a *block*, so `serializeBlock` needs its own case; its `outerHTML` fallback would otherwise write our internals into the note.
15. **Glyph never deletes content; it may escape it so it stays inert.** The sanitizer runs on render and the serializer writes the sanitized DOM back to the user's file, so anything the sanitizer *removes* is removed from their document. An unclosed `<style>` used to swallow the rest of the note and delete it on save (measured: 10 paragraphs down to 2). `guardInput` in `viewer.html` escapes swallowing tags and over-long emphasis runs before `marked.parse`, so nothing is swallowed and nothing is lost. That pre-pass is content preservation, not a security control — the DOM sanitizer stays authoritative, so a miss there is free.
16. **Both parsers are quadratic on adversarial input and both run on the main thread.** marked's emphasis tokenizer is O(n²) in `*`/`_` per line (a long run froze the app on *open*), and `GlyphHighlighter`'s inline-code rule was O(n²) via its backreference (froze ⌘E for a minute). Both are bounded now — `EMPHASIS_LIMIT` in `guardInput`, and `{1,10}`/`{1,500}` plus a 20k line cap in the highlighter. Never reintroduce an unbounded quantifier next to a backreference, and never assume a note is well-formed: an LLM emitting a wall of punctuation is enough.
17. **Never set `allowFileAccessFromFileURLs`.** It is not needed for images — those resolve through the base URL, verified — and it converts any script execution into an arbitrary local-file read.
18. **The CSP is load-bearing and has two forms.** The macOS app substitutes a fresh nonce per load in `-loadTemplateHTML` (not in `+viewerTemplate`, which is cached once per process); `make-preview.py` and `engine-smoke.mjs` pin the same inline blocks by sha256 because a static file has no per-load step. If you add or edit a `<script>`/`<style>` block, all three paths must be updated together or the page silently stops running.
19. **The autosave guard is the last line of defence for the user's files.** `-verifyRoundTrip` renders the document, asks the page what it would be written back as, and compares word bags (`GlyphRoundTripPreservesContent`). If any word would be lost, the formatted view is switched to read-only via `glyphSetProtected` and page-sourced edits are refused outright — the raw view (⌘E) stays available because it writes the file literally. The rule is deliberately blind to formatting: bullet markers, blank lines and autolinking must NOT trip it or the app becomes unusable, and entity references are stripped from both sides before counting. Measured on 264 of the owner's real files: 246 editable, 18 protected. Use `Scripts/roundtrip.m` to re-measure after any serializer change.
20. **A pipe inside `[[target|alias]]` is part of the link, not a table column break — and BOTH spellings must survive verbatim.** `guardInput` marks them before marked's table parser runs, because that parser consumes a backslash escape when it splits cells and it cannot be recovered afterwards: U+E001 marks one the author escaped, U+E000 one we escaped, and the wikilink renderer restores each to what it was. `serializeTable` skips pipes inside wikilinks so nothing is re-escaped on the way out. Never normalize one form into the other — Obsidian expects `\|` inside tables, so rewriting it changes how those files render elsewhere.
21. **The guard needs a construct census, not just words.** A paragraph holding only `&nbsp;` carries no words, so 81 deliberate blank answer lines vanished from a client brief while the word check reported it safe. `GlyphTakeCensus` counts blank-but-not-empty lines, comments, fences, images, headings and table rows, and only DECREASES trip the guard — normalization legitimately adds constructs (setext becomes ATX, blank lines get inserted) and firing on that would make the app unusable. Re-measure with `Scripts/roundtrip.m` after any serializer change.
22. **Imported HTML documents will never round-trip and should not pretend to.** Old blog captures and epub conversions carry styling in classes and wrappers that the sanitizer strips for safety before the serializer sees them, so they cannot be written back honestly. The right answer is the guard holding them read-only, not a preservation path that looks complete and is not.
